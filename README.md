# ブラウザゲーム集 / 定時サバイバー

起動するとゲーム選択画面が表示されます。既存作に加えて **Page Survivor 2 — ASTRA（定時サバイバー2）** を選べます。

## Page Survivor 2 — ASTRA

既存の男女主人公・社員・上司のドット絵を使った独立した続編です。5分間の仕事を生き抜き、最後の社長会議を倒して定時退社を目指します。ゲーム内時間5:00で最終ボスが登場し、その撃破でクリアになります。

- 移動：WASD / 矢印キー。攻撃は自動。
- ダッシュ：Space。短い無敵時間があり、再使用には待機が必要です。
- スマートフォン：戦場をドラッグして移動、右下のボタンでダッシュ。
- 強化：クリック、数字1〜3、またはTabで選んでEnter / Space。選択中は時間が止まります。
- 一時停止：P / Escape。画面を離れた場合も自動停止します。
- 音声切り替え：Mまたは「音 ON / OFF」。タイトルとポーズ画面でBGM・効果音を個別調整できます。

武器は3枠、補助能力は3枠。新しい能力を獲得するか、手持ちを育てるかを選びます。武器Lv.5と対応する補助能力Lv.2で自動進化します。

| 武器 | 補助能力 | 進化後 |
| --- | --- | --- |
| 議事録ビーム | 集中力 | 全社共有レーザー |
| 根回しオーラ | 合意形成シールド | 全方位合意フィールド |
| リマインド弾 | 仕事の効率化 | 一斉送信ストーム |
| 定時チャイム | 情報収集 | ノー残業宣言 |

90秒で課長、180秒で部長、300秒で社長が登場。赤い範囲予告、突進の進路、弾幕の隙間を見て回避します。ボスはHP半分で攻撃が変化し、短時間シールドを張ります。コーヒーはHP回復、紫の◇は経験値の一括回収、ボスの稟議書は追加強化です。

BGM・ボス曲・効果音はWeb Audioによるオリジナルの合成音です。「始業する」操作で再生を開始します。音量・ミュート・最高撃破数・退社成功回数はブラウザ内に保存します。保存や音声が利用できない環境でもゲームは継続できます。

実装は `src/games/page-survivor-2/` に分離されています。`?debug=1` は既存の初代向けで、続編の5分間は短縮しません。

## 初代：定時サバイバー

日本の起業文化を軽くパロディにした、Vampire Survivors風の2Dブラウザゲームです。
プレイヤーは若手社員として、資金調達前のピッチ資料修正、壁打ち、投資家質問、深夜通知をかわしながら定時まで生き延びます。

## Tech Stack

- TypeScript
- Phaser 3
- Vite
- Jest + ts-jest

## Run

```bash
npm install
npm run dev
```

ブラウザで表示されたURLを開きます。

短縮確認用の60秒モードは、URLに `?debug=1` を付けます。

## Test

```bash
npm test
npm run build
```

## Gameplay

- 移動: `WASD` または矢印キー
- 攻撃: 完全自動
- クリア: 5分間生存して定時退社
- 敗北: HPが0になる
- レベルアップ: 経験値を集めるとビジネス用語スキルを3択で選択
