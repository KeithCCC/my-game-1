# Codex Prompt: Number Merge Puzzle MVP

あなたはシニアReactゲーム開発者です。以下の仕様で、React + Vite + TypeScript の小型パズルゲームMVPを実装してください。

## 目的
ブラウザで遊べる「数字マージパズル」を作る。2048系をベースにしつつ、短時間で遊べるKilling Time向けの軽いゲームにする。最終的にはモバイル移植しやすい設計にする。

## ゲーム概要
4x4の盤面で、同じ数字のタイルをスワイプ方向に合体させてスコアを伸ばす。目標スコアまたは目標タイルに到達すればクリア。手詰まりで失敗。

## 技術要件
- React + Vite + TypeScript
- 外部ゲームエンジンなし
- `src/game/mergeLogic.ts` に盤面ロジックを分離
- `src/components/` にUIを分離
- キーボード操作とボタン操作の両方に対応
- 将来スワイプ対応を追加しやすい関数設計にする

## MVP仕様
### 盤面
- 4x4グリッド
- 初期タイルは2枚
- 移動ごとに新しいタイルを1枚追加
- 新規タイルは基本2、低確率で4

### 操作
- 上 / 下 / 左 / 右
- 同じ数字がぶつかると合体
- 1回の移動で同一タイルは1度だけ合体
- 動きがない場合は新規タイルを追加しない

### 勝敗
- 128到達でひとまずクリア表示
- 続行可能
- 空きセルなし、かつ全方向に移動不可ならGame Over

### スコア
- 合体した数字をスコアに加算
- Best ScoreをlocalStorageに保存

## 画面仕様
- タイトル
- Score / Best Score
- 4x4盤面
- 上下左右ボタン
- New Gameボタン
- Clear / Game Over表示

## 実装方針
- `moveBoard(board, direction)` を純粋関数にする
- `addRandomTile(board)` を分離する
- `canMove(board)` を作る
- `useMergeGame` カスタムフックを作る
- タイルにはidを持たせ、将来アニメーションしやすくする

## 完了条件

- キーボードと画面ボタンで操作できる
- スコア、ベストスコア、クリア、ゲームオーバーが動く
- TypeScriptエラーがない
- READMEに起動方法とルールを書く
